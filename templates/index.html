How it works

Getting ghosted by your coworkers? Feeling unmotivated? Want to know if it's just you?

This meter watches US Google search interest for : software nobody googles for fun. When searches run below a normal day of the week, people aren't working. The big number is today's search interest compared with the median of the same weekday over the last 90 days, so a Friday is only ever judged against other Fridays.

Why old grabs matter

Google reports the current day with only the hours it has seen so far, so a grab taken at 9am always looks like a disaster. Every pull is now archived in full. Once a day has settled, we compare that day's early reading with where it ended up; the median of those completion factors for the same hour (and, when we have enough, the same weekday) is what turns today's partial number into an honest estimate. Until three comparable grabs exist, the headline falls back to the last settled day and the live number is shown as raw.

Calibration status

Not science. Lower than normal means fewer people are googling their work tools; draw your own conclusions. Data via DataForSEO's Google Trends API.
